# لوحة إدارة منهاج

هذا المستودع يحوي ملفات الإنتاج الساكنة العامة للوحة الإدارة فقط، بما فيها مستورد JSON. لا يحوي سجلات قاعدة بيانات أو ملفات استيراد أو بيانات طلاب أو كلمات مرور أو مفاتيح خدمة. إعداد Firebase Web SDK عام، وليس سر إدارة.

الموقع: https://pls455.github.io/minhaj-admin-pages/

المستورد داخل لوحة الدخول للمدير النشط بدور super_admin أو content_admin في مشروع minhaj-fresh، حسب صلاحيات المجموعة ودون ربط ببريد محدد، ويفحص البيانات الحديثة ويعرض التغييرات الدقيقة قبل طلب تأكيد مستقل لكل دفعة. لا يستورد ملفات تلقائيًا. الموارد الجديدة مخفية حتى مراجعتها. تظل صلاحيات البيانات في Firebase دون تعديل.
