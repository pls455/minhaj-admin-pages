# لوحة إدارة منهاج

هذا المستودع يحوي الملفات الساكنة العامة لتشغيل لوحة الإدارة فقط. لا يحوي سجلات قاعدة بيانات أو حسابات مستخدمين أو مفاتيح خدمة أو كلمات مرور. تبقى البيانات الحية في Firebase، ويخضع الوصول إليها للمصادقة وقواعد الأمان. إعداد Firebase العميل داخل JavaScript إعداد عام، وليس مفتاح إدارة أو سر خادم.

لا يتيح فتح صفحة الدخول الوصول إلى بيانات الإدارة. المحتوى التعليمي وبيانات الطلاب ليست محفوظة في هذا المستودع.
